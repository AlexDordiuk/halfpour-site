# halfpour.app

Static site for Halfpour: home, Privacy Policy and Support in English and Ukrainian. Served by Cloudflare Pages from this
private repository (no build step, output directory `/`).

The pages are written in the app repository (`halfpour-ios/site/public`, see `site/README.md` there) and copied here:

```bash
cp -R ../halfpour-ios/site/public/. .
```
